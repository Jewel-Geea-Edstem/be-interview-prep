# Requirements

## Q1 Task Manager API
- R1.1 A task has title (required, max 100), description, status (TODO, IN_PROGRESS, DONE), due date (not in the past), created date.
- R1.2 Create, list, get one, update and delete tasks.
- R1.3 Filter the list by status.
- R1.4 Invalid input returns 400 with one message per invalid field.
- R1.5 Every error (validation, not found, unexpected) uses one JSON shape with the right status; unknown task returns 404.

## Q2 URL Shortener
- R2.1 Submit a long URL with optional expiry; get back a short code and short URL.
- R2.2 Visiting the short URL redirects to the original URL.
- R2.3 Every visit is counted, accurately under concurrent visits.
- R2.4 Stats endpoint shows original URL, visit count and created date.
- R2.5 Codes are at most 8 characters, unique and URL-safe.
- R2.6 Invalid URLs return 400; unknown codes 404; expired codes 410.
- R2.7 Shortening the same URL twice returns the existing active link.

## Q3 Authentication & Roles
- R3.1 Users register and log in; passwords stored as BCrypt hashes.
- R3.2 Stateless JWT authentication; tokens expire after 15 minutes.
- R3.3 Roles USER and ADMIN. Any user can view their own profile; only ADMIN can list users.
- R3.4 Unauthenticated returns 401, wrong role returns 403, both as JSON.
- R3.5 No secrets hard-coded in source.

## Q4 Product Catalog
- R4.1 A product has name, category, price, stock, rating and created date.
- R4.2 100 products are seeded on startup.
- R4.3 List with pagination and sorting by any field; response has total count and number of pages; page size capped at 100.
- R4.4 Optional, combinable filters: category, price range, in-stock only, name search.
- R4.5 Repeated single-product lookups are served from a cache; updates and deletes never leave stale data.

## Q5 Order Service
- R5.1 An order has one or more items and is all-or-nothing.
- R5.2 Stock never goes negative or is oversold under concurrent orders.
- R5.3 A retried request (same Idempotency-Key) never creates a duplicate order.
- R5.4 Insufficient stock returns 409 with a clear message.
- R5.5 Cancelling an order returns its stock.

## Assumptions
- H2 in-memory database for all features; schema generated by Hibernate.
- Everything under `/api/**` requires a JWT except `/api/v1/auth/**`; short-link redirects `/r/{code}` stay public.
- Product writes are ADMIN-only; reads are open to any logged-in user.
- An ADMIN is seeded from `ADMIN_EMAIL` / `ADMIN_PASSWORD` when both are set; registration always creates USER.

## Out of scope
- Refresh tokens, distributed cache, real database, custom short codes.
